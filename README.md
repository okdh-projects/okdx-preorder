# Preorder Hub

Создай адаптивный сайт для предзаказа мерча строго по этому скриншоту. Используй стек React, Tailwind CSS и Lucide React для иконок. Приложение должно быть настроено как Single Page Application (SPA), готовое для бесплатного деплоя на GitHub Pages. Настрой рабочую корзину. Пользователь может добавлять товары, выбирать размер и цвет товара (если они есть (настраивается через админ-панель)), менять количество и видеть общую сумму. При нажатии «Оформить заказ» должна открываться форма с полями: Имя, Telegram (@username) и Телефон. Создай папку public/images/ для всех картинок, в том числе и логотипа. Используй их в коде. Пути к изображениям должны быть относительными, чтобы они корректно отображались как локально, так и после сборки.
